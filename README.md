# Excel Minor Project – Sales Operations Analytics

## Project Overview

This project focuses on Sales Operations Analytics using Microsoft Excel. It analyzes sales data from a multi-category retail business operating across six Indian cities.

The project uses Excel functions, data cleaning techniques, conditional aggregation, PivotTables, and advanced formulas to solve real-world business problems and generate meaningful insights.

## Objectives

* Analyze sales and order data.
* Identify duplicate records and data inconsistencies.
* Retrieve information using lookup functions.
* Calculate total and average sales revenue.
* Analyze sales performance by region and product category.
* Compare actual sales with monthly targets.
* Rank sales representatives based on revenue.
* Generate useful business insights.

## Tools & Technologies

* Microsoft Excel
* VLOOKUP
* INDEX and MATCH
* SUMIFS and COUNTIFS
* AVERAGEIFS
* IF and nested IF
* PivotTables
* Data Cleaning
* RANK and LARGE
* TEXTJOIN

## Dataset Description

The project contains the following datasets:

1. **Orders** – Contains order details, dates, customer IDs, product IDs, sales representatives, discounts, and revenue.
2. **Customers** – Contains customer information, age, city, customer segment, and signup date.
3. **Products** – Contains product names, categories, cost, selling price, and product status.
4. **Sales_Reps** – Contains sales representative details, regions, and team leaders.
5. **Targets** – Contains monthly sales targets for each sales representative.
